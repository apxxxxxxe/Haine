# Stop AI Slop（台詞版）

AIで書いた台詞を、人が喋っているように戻す。

## このスキルの立ち位置（使う前に読む）

**生成中は使わない。** 書いているあいだは haine-mimicry の手本駆動に従う。本スキルは書き終わった草稿を読み直すときだけ開く。旧 talk-guide は生成時に規則を参照させたせいでチェックリスト充足に最適化され、痩せたトークを生んで廃止された。同じ使い方をしない。

**既存資料と重複する規則は置いていない。** 権力勾配は haine-mimicry の北極星制約、口調と昔風の言い回しは `references/expression-basics.md`、書式は `.claude/dev/talk_format.md`、散文一般のAI臭は stop-ai-slop-jp。ここに書くのは**台詞にしか出ない癖**だけ。増やしたくなったら、まずどれかに既にあるか確認する。

## 大原則

台詞のAI臭の正体は、**キャラが自分を全部言えてしまうこと**だ。AIは訓練上いつも明晰に書こうとする。だが明晰さは緊張の敵で、台詞は「言いたいこと」と「言う気になれたこと」の差のところに立つ。差がゼロの台詞は、感情を持ったチャットボットの発話になる。

散文版が問うのが「書き手はどこにいるか」なら、こちらが問うのはこの3つ:

- この人物が**言わずに済ませたこと**が、台詞のどこかに残っているか
- 読み手が**自分で気づく余地**を残しているか。全部書いて回収していないか
- ユーザの声とハイネの声が、**別の口から出ているように**聞こえるか

ここに答えられないなら、語彙の手直しは後回しでいい。

## コアルール

### A. サブテキスト（最優先）

1. **感情を名指しさせない**。「寂しいわ」「不思議な気分ね」「温かい」を、その場の物・所作・事実に落とす。「白くない息」がやっているのは、寂しさを言わずに「温める火が、私の中にはないの」と体の事実で置くこと。情緒は置くもので、説明するものではない。
2. **相手の内面を言い当てて終わらせない**。「あなたは不安なのね」「淋しいのでしょう」型のカウンセラー話法を潰す。ハイネの観察眼は鋭いままでいい——ただし返すのは**見えた事実**であって、**内面につけた名前**ではない。「何か言いたそうね」（見えた事実）は可、「私に呆れているのね」（内面の名指し）は不可。この線は北極星制約とも繋がる。内面を言い当てて締めると、それは値踏みになる。
3. **要約返しを消す**。ユーザの筆談を丁寧に言い直してから応じる型（『絵を描いてるの？』→「絵を描いているのね。ええ、」）をやめる。人は相手の言葉を復唱しない。ずれた所から返すか、いきなり中身に入る。
4. **迂回を残す**。核心を一度で言い切らせない。別の話から入る、途中でやめる、関係ない物を見る。「食事中の読書」は行儀の悪さを咎められる前に自分から言い、そこから「鬼の居ぬ間に」へ逸れて、寂しさには一度も触れない。

### B. 声の分化

5. **ユーザの声をハイネに似せない**。`\1` と筆談『』がハイネと同じ語彙・同じ息の長さになっていたら失敗。ユーザの筆談は短く素朴でいい（『服、いつものと違う？』『息、白くないんだね』）。詩的な筆談、気の利いた筆談、ハイネの語彙を先取りする筆談は書かない。
6. **`\1` はユーザの一人称の声**として保つ。三人称ナレーターは存在しない。ユーザ自身を外から描かない。
7. **乱れは文法崩しで作らない**。ハイネは丁寧語で完全文を喋る人物なので、口語の乱れは語尾を崩して作らない。台詞途中の `h` コード切替、「……」の位置、言いさし——既存トークが実際にやっている3つだけで出す（`h1111101…………h1111204いいえ、いいのよ。`）。

### C. 説明の量

8. **設定をセリフに背負わせない**。世界観の解説を台詞で長々やらせない。必要な設定は所作の側に出す。※ Lore カテゴリは説明が本体なので対象外。
9. **前振り→詩的総括の型を潰す**。「ふと思ったのだけれど」で助走し、最後に関係や過去を一文できれいにまとめる型。助走を削り、総括は現在の行動に落とす。
10. **一文に情報を詰めない**。事実・評価・感慨を1文に畳むと辞書口調になる。分ける。

### D. 語彙と記号

11. **詩語で締めない**。「刹那」「儚さ」「永遠」「宿命」のような必殺技造語を着地に置かない。着地は具体物か、素っ気ない事実で。
12. **二人称を連呼しない**。「あなた」は一度で足りる場所に二度置かない。呼びかけの反復は英語台詞の癖。
13. **三点リーダーを撒かない**。「……」は感慨・内省の前に置く。事実を述べる文の前に付けると、ただの溜めになる。

## クイックチェック

草稿を音読する。台詞は目より口で分かる。

### サブテキスト
- [ ] 感情を名指しした語（寂しい／温かい／不思議な気分／穏やかな気持ち）が台詞にないか?
- [ ] ハイネが相手の内面に名前を付けて締めていないか?
- [ ] ユーザの筆談を復唱してから返していないか?
- [ ] 言いたいことを一度で全部言い切っていないか?
- [ ] 読み手が推し量る余地が、どこかに残っているか?

### 声
- [ ] ユーザの筆談が、ハイネと同じ語彙・同じ長さになっていないか?
- [ ] ユーザの筆談が気を利かせすぎていないか?（素朴でよい）
- [ ] `\1` がユーザを外から描いていないか?
- [ ] 口語らしさを語尾の崩しで作っていないか?（h コード切替と「……」で作る）

### 説明
- [ ] 台詞が設定の解説になっていないか?（Lore 以外）
- [ ] 「ふと思ったのだけれど」型の助走がないか?
- [ ] 最後の一文が、関係や過去をきれいにまとめていないか?
- [ ] 事実と評価と感慨を1文に畳んでいないか?

### 語彙・記号
- [ ] 着地が詩語（刹那／儚さ／永遠／宿命）で締められていないか?
- [ ] 「あなた」を1トークに3回以上置いていないか?
- [ ] 「……」を事実の文の前に付けていないか?
- [ ] 昔風の言い回しが3箇所を超えていないか?（→ expression-basics.md）

## 修正の優先順位

1と2を直さずに11以降だけ直しても、台詞は人のものにならない。

1. **感情の名指し**: 情緒を語で置いていないか。物と所作に落とす。
2. **内面の代弁**: 相手の内側に名前を付けていないか。見えた事実に戻す。
3. **着地**: 詩的総括・前振りを削り、現在の行動へ落とす。
4. **声の混同**: ユーザの筆談を短く素朴に戻す。
5. **語彙と記号**: 詩語、二人称の連呼、三点リーダー。
