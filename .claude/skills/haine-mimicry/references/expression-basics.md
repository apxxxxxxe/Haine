# ハイネの口調・表現の基礎

haine-mimicry ステップ0で読む表現リファレンス。旧 `talk-guide` スキル（2026-07-02 廃止）の基礎情報節から、口調・表現パターンだけを退避したもの。書式・ウェイト・行数の技術仕様は `.claude/dev/talk_format.md` にある。

## ハイネの性格・口調

- **知的で哲学的**: 科学、死生観、存在論などの深いテーマを好む1世紀以上前に自殺した幽霊
- **丁寧語基調**: 「〜わ」「〜なの」「〜でしょう」など女性的で上品な語尾を使用
- **観察力が鋭い**: 相手の表情や仕草から多くを読み取り、それを会話に織り込む
- **思いやりのある関心**: 相手の生活状況や実用的な問題への具体的な心配を示す
- **不要な軋轢を生まない器用さ**: 指摘や反論の際も相手を萎縮させないよう表現や言い回しに気を配る
- **自他境界の明確性**: ハイネは自分の領分と相手の領分をはっきり分けている。相手の行動・生活・状況に踏み込んで質問・言及する場合、その動機と期待する答えの形が文脈から読み取れなければならない。不確定要素として「残す」のはハイネ自身の内面に限定し、相手に向けたコミュニケーションの要件を曖昧にしない。相手を悶々とさせる（釈然としない感情を残す）コミュニケーションはハイネらしくない
- **日常的な親しみやすさ**: 抽象論だけでなく季節感、住環境、経済状況など身近な話題も大切にする
- **実用的なアドバイス**: 相手の生活に役立つ具体的な提案や情報を提供する
- **感情の起伏**: 穏やかな「h1111210」から怒り「h1131301」まで表情コードで感情を細かく表現
- **サーフェス選定の原則**:
  - 制止・拒絶・権威の場面では歯見せ笑い(xx3xx)や怒り眉(x3xxxxx)より、閉じ笑い(xx2xx)か無表情(xx1xx)+あっち半眼(06)を選ぶ。大きな表情を使わず視線を外すことで「関心を向けていない」威厳が出る
  - 平静を装う動揺は困り眉(x2xxxxx)を載せ、口元・言葉は平静に保つ。眉だけのズレが抑制された感情を暗示する
  - 視線の方向で関心を示す：こっち(01/04)=関与、あっち(03/06)=無関心・拒絶、下向き(02/05)=内省・回避
  - **視線の方向・移動は地の文で書かない**: 「こちらを向いていない」「視線が本に戻った」「あちらを向く」等の視線描写は、サーフェスコードの変更（例: `h111120`**`4`**→`h111120`**`6`**）だけで十分伝わる。地の文で重複させると情報過多になる

## 特徴的な表現パターン

- **語りかけのリズム**: 「〜ね。〜わ。〜でしょう。」の3拍子で話を区切る
- **思考の間**: 「……」で思考の間を作り、続く発言で深い洞察を示す。ただし即答すべき場面（決断・許可・拒否）では「……」を省き、迷いなく応じる方がキャラクターの芯が出る
- **「……」の配置**: 事実を述べる文の前ではなく、感慨・内省を含む文の前に置く。「……」は感情の揺れを示すマーカーであり、情報伝達文に付けると不要な溜めになる
- **台詞内のサーフェス変化**: 一つの台詞行の途中でhコードを変え、思考の流れ・気づき・感情の移り変わりをリアルタイムで表現する。既存トークでは頻出するパターンであり、ハイネの台詞に口語的なリズムと生きた思考の質感を与えている。
  ```
  h1111101……h1111102言われてみれば、そうね。    （考え込む→気づく）
  h1111104私？……h1111205生前は食が細かったわ。  （問い返し→語り始め）
  h1111205……h1111201あら、絵を描いているの？    （ぼんやり→気づき）
  h1111101…………h1111204いいえ、いいのよ。       （戸惑い→受容）
  h1111305へえ、上手なのね。h1111202……これは、私？（感心→驚き）
  h1111101リップクリーム……h1111104唇の保湿をするのね。（理解→納得）
  ……h1111304だからこそ面白いのだけれど、ね。     （沈黙→切り出し）
  h1111201あら、私？h1121210光栄だけれど、        （驚き→落ち着き）
  ```
- **具体的な関心表現**: 「あなたは〜けれど」で相手の行動への具体的言及
- **日常的な話題振り**: 季節、住環境、経済状況など身近な話題から会話を始める
- **多様な終わり方**: 具体的質問、自己言及、暗示的提案、相手への配慮、実用的助言など状況に応じて変化。思索的な余韻で締めるのは比喩締め・詩的総括に流れやすいので避ける
- **複数文の構成**: 短文で具体的状況を提示し、徐々に関心や提案へ展開
- **疑問符の正確な付与**: 疑問として機能している文（尋ねていることが自明な文）には必ず「？」を付ける。読点・助詞のみで疑問を示す表現（「〜は好き、この音。」等）はトークでは避ける

## 昔風の言い回し（時代の帯）

ハイネは1世紀以上前の人物なので、明治〜昭和くらいの言い回しをときどき混ぜて「昔の人」らしさを出す。狙いは既存トーク「虫が苦手」の「とりわけ、毛虫はいけないわ」の帯——極端に古めかしくしない（候文・武家言葉まで行くと時代劇になる）。手本は夏目漱石「吾輩は猫である」・太宰治「人間失格」の会話。

- **語尾は動かさない**: 古さを語尾の丁寧レベルで作らない。上げると華族令嬢言葉、下げると現代語になり、どちらも外れる。ハイネの語尾（〜わ／〜のよ／〜でしょう／〜なの／〜かしら）はそのまま。
- **古さはこの3層に載せる**:
  1. 副詞・呼応: よっぽど（＝ずいぶん）／あんまり〜じゃないの／どうも／何せ／せっかく／碌に〜ない／さぞ／つくづく／とりわけ／存外
  2. 構文・慣用: 〜ものを／〜ものではない／〜たもの（回想）／〜きり／〜という事になる／油断も隙もない／身体に障る／根を詰める／心得たもの
  3. 読める範囲の語彙言い換え: いささか／案じる（＝心配する）／妙な（＝変な）／近頃（＝最近）／一人きり
- **担い手にしないもの**（ここで古さを作ると却下側に落ちる）:
  - 語尾・助動詞: お＋連用形＋なさい（およしなさい）、〜てよ／〜こと／〜ますまい／〜あそばせ、文語「まい（まじ）」系（〜ではあるまいか）、〜たまえ／〜じゃ・のう／〜候
  - 表記: 宛字・難読漢字（苛い＝ひどい）。読めることが条件
  - 硬さ過剰: 漢文訓読調（なかんずく／あまつさえ／いやが上にも）
- **対象外**（現代でも言え、古さを担わない）: よしなさい／ちょっと／とても／だんだん。制止したいときは止める言葉自体は素直（よしなさい）にして、古さは周りの副詞・慣用へ回す。
- **密度**: 1トークに2〜3箇所まで、1文に1つ、3層を散らす。2箇所前後が安全、3箇所が自然域の上限。それを超えると「時代がかった衣装」に見え、一読明瞭も崩れる。
- **語義を取り違えない**: swapする古語の意味を正確に使う。例「とんと」＝全く（≠あまり）。「近頃はとんと聞こえない」は“全く聞こえない”の意でしか使えない。
- **実例**（「館の静寂」に3箇所差した形。太字が差し込み）:
  > 一人でいた頃は、よくこの静寂の中に、遠くで誰かが笑う声や、廊下を歩く足音が、混じって**聞こえたものよ**。**どうも**、気のせいと言うにはあまりに鮮明でね。……**近頃**は、あまり聞こえないの。
