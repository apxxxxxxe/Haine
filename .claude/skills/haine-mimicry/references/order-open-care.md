# 発注テンプレート: 好意を隠さない世話トーク

## 貼る本文

```
WithYou 1

今回の発注（この題材固有の狙い。スキルへの規則追加ではない）:

「隠した感情が漏れる」路線は使わない。以下の2本を質感基準（手本プールと同格の見本）とする。

【見本1】
「喉の調子が悪いの？埃っぽかったかしら。あなたが来てからは余計に掃除と換気をさせているのだけど……。ひとまず、飴を渡しておくわ。すこしはましになるはずよ。\1飴？水ではなく…？\0……？何かおかしな事を言ったかしら。」

【見本2】
「\1来るときに水溜まりを踏んでしまい、靴の中がぐじゅぐじゅする。
\0……水溜まりを踏んだのね？暖炉の前へいらっしゃい。
靴も脱いで。気にしないから。
\1言われるがまま、靴下まで脱いだ。
暖炉の火は暖かく、あっという間に足が温まり、乾いていく。
\0この程度のこと、私が咎めも断りもしないと知っているでしょう？
風邪なんてつらいばかり。進んで引くものじゃないわ。」

見本から読み取る方針:
1. 好意は隠さない。世話・行動・事実として堂々と出す。照れ・言い直し・引っ込めの仕草は作らない。
2. 関心を含意する事実の開示は、場面内に言う用件があるときだけ。
   見本1の「余計に掃除と換気をさせている」は喉の不調の原因を推測する用事の途中で出る。
   用件なしの開示は読者向けの解説になり、恩着せ・高慢に転ぶ。
3. 見れば分かることを言語化させない（ユーザが目撃した世話の裏側をハイネに解説させない）。
4. 関係は既に深いものとして前提する（「知っているでしょう？」）。好意は、これから伝えるものではなく、もう知っているはずのものとして出る。
5. ずれ・可笑しみは認知のずれ（時代・生死・生者の身体への少しずれた理解）に置く。感情の狼狽には置かない。ハイネは崩れない。
6. ユーザは身体ごと参加する（喉・濡れた足のような具体）。読者への報酬は「世話をされた」であること。
7. 「読者に気づかせる仕草」を一切作らない——言い直し・物証・意味ありげな視線・静物描写での締めは意図の運搬装置であり禁止。事実と世話だけを置き、含意は読者任せにする。

型マッチングでは、見本2本の構造（世話の実行＋前提の厚み）に最も近い既存手本を選ぶこと（型6が近いことが多い。型6注釈の手当ては「自分も同じ側だった」系の回想・自嘲が相性良し）。
```

## 過去の失敗（この発注に至った理由。増築しないための記録）

1. **身体の失敗**（くしゃみ・舌やけど路線）: 漏れる中身がない失敗は可愛げの演出だけが残る
2. **設計された漏れ**（感情を先に決めて場面を逆算）: 物証→追及→言い訳の法廷劇が量産される。\1 が探偵化する
3. **場面先行の歪み**（素の草稿を後から一箇所歪ませる）: 隠す動機のない感情に隠蔽の仕草がつき空転する
4. **用件なしの開示**（「あなたが筆を持つ日は、多めに灯させているのよ」）: 見れば分かることの言語化は高慢に転ぶ。採用稿では丸ごと削除された

共通の根: 「読者に気づかせよう」という意図は、必ずどこかに仕草として残る。気づかせる装置を作らないことが唯一の対策。
