# カンテルベリオ — 街の構成・地理の詳細

トーク作成時に街の描写が矛盾しないよう、区画・施設・地形の設定を一元管理する。`mansion_layout.md` の街版。物理・地理の台帳に徹し、霊的地理・霊体社会（なぜ霊が集まるか、霊力の階級、契約など）は `haine_about.md`「世界観」「霊体社会」節を SSOT とする。

## 前提：街とハイネの距離

台帳を読む前に、ハイネと街の関係を押さえる。街の描写はこの距離のうえに乗る。

- **ハイネは館にほぼ留まる**。街（霧の内側）へ出ることは幽霊として不可能ではないが、身体が弱くそこまで行くのが難しく、老いない姿では生者のふりを続けられない。だから行かない。ただし**街の今に暗いわけではない**——霊体商人との世間話、外回りを命じた従者の報告、文通相手などから、現況は相応に入ってくる（`haine_about.md` 霊体商人／situations 413）。自分の足で見て回らないだけ。
- **町の外（霧の範囲外）へは行かない**。町の外れ、霧が切れるあたりで存在が薄くなる。戻れる保証がないから越えない（situations 416）。霧の範囲が実質の行動圏。
- 結果、ハイネの語りには**生前の記憶（約1世紀前・学府の町）と、報告で知る現在（寂れ気味の観光地）が両方**現れる。台帳は「今そこにある街」を土台に書く。ハイネは現況も承知しているが、自分の目で見ていない伝聞の距離は残る。記憶と現況の落差そのものがトークの素材になる（「私の知る講堂も、今はもう違うと聞くわ」）。

## 霧の濃度と三帯（館からの距離）

霧は街全体を覆う。濃度は一様ではなく、古い区画（館のある一帯）を中心に濃く、街の中心へ向かうほど薄れる。ただし中心部でも完全には晴れない。町境で切れる。

```
[町境：霧が切れる＝範囲外]──[帯1 古い区画：霧の中心・最濃]──[帯2 中心部：霧は薄いが残る・現代の生活圏]
  ↑ハイネの行動限界                ↑館・修道院跡・旧学舎             ↑駅・商店街・宿・住民
  （この先へは行かない）           （学問の亡骸が霧に沈む一画）        （寂れ気味の観光地）
```

| 帯 | 霧 | 時代の手触り | 主な要素 |
|----|----|--------------|----------|
| 帯1　古い区画 | 最も濃い | 前時代の空き家が残り、現代人はほとんど住まない | 館、修道院跡（鐘塔のみ）、旧学舎、古い市門、石畳の路地 |
| 帯2　中心部・生活圏 | 薄いが残る | 現代。寂れ気味だが人が暮らし観光客が来る | 駅、商店街、宿、小劇場、カフェ、診療所、役場、教会 |
| 帯3　町境 | 切れて範囲外 | ── | 崩れた城壁、街道、この先は野 |

館は帯1に属す。街は帯1から帯2の一方向にだけ広がり、館の背後（帯3側）はすぐ霧が切れて何もない。館は「街の突き当り」。

## 下敷き：カンタベリー

カンテルベリオは実在の**カンタベリー**（英・巡礼と学問の大聖堂都市）の成れの果てとして構想する。既存の確定設定は、そのまま各要素の「寂れた姿」に対応する。

| カンタベリー | カンテルベリオ（寂れた姿） |
|--------------|----------------------------|
| 大聖堂・修道院（巡礼の目的地） | 廃れた大修道院。鐘塔のみ残存 |
| 生者の聖地巡礼 | 巡礼は絶え、死者・霊が霧に引かれ流れ着く |
| 学問の町（最古級の学校・大学） | 学問が去り、旧学舎は廃墟・一部転用 |
| 城壁・市門・ローマ遺構 | 崩れた城壁と古い市門、遺構が残る |
| 街を流れる川 | 霧を立てる川。三途の川と重なる |
| 賑わうハイストリート | 半分シャッターの商店街 |

宗教色は薄める。現役の大聖堂は置かず廃墟（＝修道院跡）に集約し、「生者の巡礼」を「霊の集積」に読み替える。現代の生者の信仰は小さな教会ひとつだけ残す。

## 帯1（古い区画）施設の詳細

かつての学府地区。前時代の空き家・廃墟が霧に沈み、現代人はほぼ住まない。館もここ。帯1は一様に無人ではなく濃淡がある——**帯2寄りの縁（修道院跡）までは観光客が史跡見学に来て、奥へ行くほど霧が濃く人けが絶え、突き当りが館**。市門が観光客の実質の立ち入り境界。館そのものの内部は `mansion_layout.md` が担当し、ここでは街の中の位置づけのみ。

### 修道院跡

- **鐘塔のみ立つ**。聖堂本体は崩れ、礎石・崩れた壁・回廊跡が残る。史跡として観光客が見学に来る（観光の表看板）。帯1の帯2寄りの縁。
- **鐘はもう鳴らない**（randomtalk「鐘の音」）。かつては死者のためのパッシングベルを鳴らし、月に一度の祭日を告げた（「街の風習・行事」節）。
- **付属の古い墓地**：古い墓石が霧に沈む。randomtalk の人魂・墓地の話の舞台に使える。帯2の教会墓地とは別。

### 旧学舎（近代の学府）

- 近代の学府の校舎群。廃墟（蔦・割れた窓）。「学問の中心地」の近代の層。
- ハイネ生前（約1世紀前）の最盛期を彼女は覚えている。立入はまれ。帯2の郷土資料館に移された展示物の出所。
- 「下敷き：カンタベリー」の二層（中世＝修道院の学問／近代＝この学舎）のうち近代側。

### 市門・城壁・路地

- **古い市門・崩れた城壁**：帯2（中心部）と帯1（古い区画）の境。市門をくぐると霧が濃くなり古い区画へ入る。観光客はここをくぐって修道院跡まで来る。城壁は町を巡り、帯3（町境）側にも崩れて残る。市門＝観光客の実質の立ち入り境界。
- **石畳の路地・空き家**：修道院跡の奥、館へ向かう一帯。前時代の空き家が並び人けがない。霧が最も濃く、観光客も来ない。館はこの突き当り。

## 帯2（中心部）施設の詳細

粒度を高めた主要施設。固有名詞は原則付けず、トークで呼ぶ必要が出たとき随時。

### 商店街

カンタベリーのハイストリートが下敷き。生活の店と観光の店が混在する目抜き通り。

- **構え**：石造りの古い商店建築が並ぶ目抜き通り1本と脇道。半分シャッター。店主は高齢が多く、後継者不在で店じまいが進む。「かつての器に人がまばら」を通りの単位でも反復。
- **生活の店**：食料品店、パン屋、雑貨・金物屋、**古書店**（学問の町の名残。ハイネの蔵書・読書文化と遠く響き合う。話題の受け皿）。
- **観光の店**：土産物店（修道院の鐘・霧の街並みの絵葉書や版画・怪談本）、茶葉店、菓子店。
- **祭日にまつわる品**：月に一度ほどの地元の祭日（死者を迎え送る行事。「街の風習・行事」節参照）に向けた品を扱う。霊よけの蝋燭、戸口に吊るす飾り、供物の類。観光客には奇習、地元には当たり前——「公然の秘密」が生活風習に溶けた証。
- **生者の生活物資**：ユーザが生鮮・日用品を得られる場。ただし**唯一の販路ではない**（通販など他の便もある）。館の食料は霊体商人の注文制（`mansion_layout.md`）で、これとは別系統。

### 教会

現代の生者の信仰施設。帯1の修道院跡（廃墟）とは別。

- **規模・現役性**：中心部の外れの小さな古い教区教会。高齢の司祭が一人、信徒はわずか。日曜の礼拝と生者の葬儀を細々と担う。
- **宗派**：ぼかす。「古い教区教会」程度に留め、特定の教派名は出さない。自殺や救済をめぐる神学的なタブーは持ち込まない（この世界観はそこまでキリスト教的ではない）。
- **教会墓地**：古い墓地が付属。ほぼ埋まり新規の埋葬はまれ。帯1の修道院跡付属の古い墓地とは別。
- **祭日との棲み分け**：月に一度の祭日は民間習俗で、教会は関与が薄い。教会の鐘は礼拝用で、祭を告げる役ではない（それは失われた修道院の鐘の役割だった）。制度宗教と民間信仰が並存し、互いに干渉しない。
- **ハイネの墓**：教会墓地にはない。館は元家族の別荘＝ハイネの生家で、家の墓所は館の側にある（詳細は `mansion_layout.md` / `haine_about.md` の領域。ここでは「教会墓地には無い」事実だけ置く）。ハイネはこの教会に足を運ばない（街に出ない＋縁がない）。

### 小劇場

確定施設（haine_about 209）。かつて貴族の社交場、現代に転用され細々と現役。

- **かつて**：貴族・名士の社交場。舞台と客席、装飾的な内装。ハイネ生前（約1世紀前）の最盛期。**ハイネ個人との接続**：randomtalk「生前の社交性」（社交的とは言えず、社交の場でも本を読んでいた）に乗せ、ハイネも家族に連れられて来たが馴染めず隅で本を読んでいた、とできる。
- **現在**：建物は残り、地元の多目的ホール兼、観光客向けの小演目（怪談の朗読会、地元劇団の公演、古い映写など）に細々と使われる。老朽化し往時の華はない。
- **ハイネの視点**：生前の華やかな記憶と、報告で知る今の寂れた姿の両方を語れる（実見していないだけで、暗いわけではない）。記憶と現況の落差が素材。

### その他の帯2施設

接点が薄めなので一括。いずれも寂れ気味で規模は小さい。

| 施設 | 粒度 |
|------|------|
| カフェ・食堂 | 観光客向けのカフェが数軒＋地元の食堂が一つ二つ。祭日にちなむ菓子・地元の焼き菓子（茶葉店・菓子店と連携）。ハイネの茶の時間（館・静か・従者給仕）と、街のカフェ（生者・観光・賑やか）の対比。ユーザの街での飲食の受け皿 |
| 診療所 | 小規模。高齢の医者が一人。急病・大怪我は町外の病院へ搬送（道路での往来あり）。ユーザの怪我・体調の受け皿。生者の医療で、霊であるハイネには無縁 |
| 役場・駐在所 | 最小限の公的機能。小さな役場と駐在所（警官一人程度）。「公然の秘密」を騒がず淡々と処理する地元行政の顔。怪異の噂も事件化しない。館の侵入者（肝試し）を稀に補導する程度 |
| 駅 | 単線ローカル線1本の途中駅か終着。無人〜駅員数人。観光客の玄関口。駅前に寂れた商店とバス・タクシー乗り場。※ユーザは街道を歩いて来た＝駅は未経由 |
| 宿（観光旅館） | 寂れた観光旅館が数軒。最盛期の器に客まばら。古い木造・石造の宿。背景でユーザ動線には絡めない（館に泊まるため） |
| 郷土資料館・遺構 | ローマ〜中世の遺構、修道院・学問史、霧の伝承を展示。史跡観光の表看板。小さく寂れ気味。※ハイネ本人にまつわる展示は無い |

## 街の風習・行事

### 月に一度の祭日（死者を送る行事）

死者を迎え、留まらぬよう送る地元の行事。カンタベリー＝聖地巡礼・死者を悼む祭の伝統を、霧と霊の町に翻案したもの。固有名詞（祭の名）は保留。

- **頻度と暦**：月に一度ほど、霧が特に濃くなる夜に行う。霊の集積地ゆえ死者が絶えず流れ着くので、年に一度ではなく月ごとに迎え送る。霧が濃い＝霊が活発（確定設定）に合わせる。
- **内容**：各戸が戸口に霊よけの灯を点し、供物を出す。地元は淡々と習俗としてこなし、観光客は幻想的な光景・怪談として消費する（確定の温度差）。寂れ気味の街の数少ない見せ場。
- **鐘**：かつてはこの夜を修道院の鐘（パッシングベル）が告げた。今はもう鳴らない（randomtalk「鐘の音」＝あの鐘が最後に鳴ったのはいつだったか）。祭は各戸の灯だけで細々と続く。商店街の霊よけの品も、鐘の代わりに家々が担うようになった名残。
- **霊の側の視点**：これは生者が死者を思う行事であって、当の死者（霊）にとって特別な意味はない。霊は特別扱いを求めず、特別な過ごし方もしない。ハイネも街の祭には関わらない。生者の弔いと、当の霊の無関心——この温度差がトークの素材になる。

## ないはず

|----------|------|

- **ハイネが街（霧の内側）へ出ない理由**：幽霊として出られないのではなく、身体が弱くそこまで行くのが困難＋老いない姿では生者のふりを続けにくいから。situations 416（町の外＝戻れる保証がない）を補完する新事実。`haine_about.md` か situations へ反映する価値がある。
- **ハイネの墓／家の墓所は館の側にある**：教会墓地にはない。館は元家族の別荘＝生家なので、家の墓所が館の敷地側にある。土地との結びつきの深さ（高位霊である理由）とも整合する。`mansion_layout.md`（館の敷地）／`haine_about.md`（人物）へ反映する価値がある。
