# 現行トークから読み直したハイネ

**このファイルの役割**：今リポジトリに入っている台詞そのものを下から読み、そこに実際に描かれている人物を拾い上げた観測記録。あわせて、行き詰まったときに人物像へわざと壊れた変更を入れて抜け出すための実験場を兼ねる。

`haine_about.md` との分担：

- `haine_about.md` は **canon の SSOT**。台詞から出てこない確定設定（三サイズ・身長体重・いとこの子孫が家を管理・霊体商人など）もここが持つ。動かさない。
- 本ファイルは **「現行の台詞が実際に描いている人物」の観測**。canon ではなく、コーパスを読み直すたびに上書きしてよい。ここで見つけたドリフトのうち、canon に昇格させるべきものだけを別途 `haine_about.md` へ書き戻す。

**方法の前提**：面白さを理論から演繹しない。ここに書くのは「既に出荷された台詞に何が反復しているか」の後追いの記述であって、生成公式ではない。詳しくは記憶 `lore-theory-is-diagnostic-not-generator`。

最終読み直し：2026-07-05（ブランチ kkk）。台詞側は 2026-07-02 の読みのまま＝`randomtalk.rs`（約90本＋派生7本）・`first_boot.rs`・`bootend.rs`。`situations.md` は全466問を読み直して反映済み（位置づけと範囲ごとの扱いは1章末尾）。

## 1. 現行の台詞から立ち上がる人物

台詞を「何が反復しているか」で束ねると、次の八つが繰り返し出てくる。各項に代表トークの id を付す。

### (1) 相手の身体・所作を読み当てる
打ち明けではなく兆候から言い当てる。物語の入口（`first_boot`「声が出せないのでしょう？」→「表情を見ているだけ」）と出口（`on_vanish_selecting`「顔に書いてあるもの」／`on_vanish_selected`「ちゃんと見られていた」）が同じ動作で締まる。日常でも `くしゃみ`「ずっと見てたの？」・`独り言の癖`「聞こえていたの？」・`生きた字`。
→ 芯ではなく癖として扱う（理由は記憶 `lore-theory-is-diagnostic-not-generator`）。ただし反復量は多い。

### (2) 平凡な物理の所作にトークをぶら下げ、感情は傍らに落とす
`菓子の切り分け`・`舌やけど`・`振り子時計の調整`（直せず悪化させる）・`蝋燭の交換`（素手）・`刺繍のハンカチ`・`朝の髪`・`袖のほつれ`。WithYou は「ハイネが何かしている \1 ト書き」で開く型が主流。好意や気遣いは所作の脇にそっと落ちる。

### (3) 百年物の幽霊なのに人間くさい未練・癖が残っている可笑しみ
`泳げない`（もう溺れないのに試したい）・`舌やけど`＋派生（実は感覚を訓練で取り戻した）・`食べ物の好き嫌い`（レーズン嫌い）・`携帯電話を使わない`・`生前の社交性`。本人は不条理を淡々と受ける。Comical(UnawareContradiction) が一カテゴリ分を占める。

### (4) 自分の死・自殺を平叙で、しばしば乾いた落ちで語る
`人ひとり`「だから私は私を殺したの」・`死の瞬間`「後悔はなかった……遺書くらいは書いたほうが」・`死なない理由`・`惨めな人生`。自己憐憫はない。DryHumor の button が付く。

### (5) 死の民俗・科学を「もてなし／贈り物」として差し出す
Lore 約19本。末尾を問い（`冥界の渡し賃`「あなたなら〜と思う？」）か自分の話（`鏡を覆う`→「私は映るわよ」／`デスマスク`→「私のも取っておけば」）に折る。講義で終わらせない。

### (6) 救う／救われる役を拒み、関係を「見届け合い」に置き換える
`first_randomtalk`「私があなたを救うこともない」・`中途半端な助け`・`あなたの価値`「何も要らない、ただ息をして、ここにいて」・`わがままな祈り`「理解できなくても見ていてほしかった」・`first_close`「看取らせてほしい」。

### (7) 停滞を恐れ、壊してでも変化を取りにいく能動性
`停滞の破壊`「多少無理にでも変化を……たとえなにかを破壊することになるとしても」・`停滞を終わらせるために`・`極限の変化としての死`。受け身の憂鬱ではなく、変化への飢え。下記「4. 破壊で停滞を抜ける」はこの気質を作業手順に写したもの。

### (8) 和らげられていない morbid な嗜好（歯）
`人を解体したい`・`極限の変化としての死`「その一瞬が愛しくてたまらない」・`死体損壊`の平然。ここを丸めると人物が痩せる。

### situations.md の回答が足す輪郭

`situations.md` は場面別の質問集で、全466問が回答済み。出荷台詞ではないが、回答のいくつか（7 好き嫌い・12 くしゃみ・144 服の修繕・149 リップクリーム）はそのまま出荷トークの原型になっている。つまり台詞と canon の中間の層——人物決めの一次資料 兼 トークの種——として読める。以下、番号は situations.md の項番。

範囲ごとに扱いが違う。**150〜299 は現代パロ想定の回答**（エレベーター・テレビ・メールなど）で、場面がハード canon（電気がない・現代技術を避ける）と両立しない。ここから拾ってよいのは判断の型だけ——初回は完璧に従い二回目から改造する（200・255）、損益を計算してから動く（233・297）、他人の都合で自分のリズムを崩さない（209）——で、**場面ごとトークの種にはできない**。300〜436 は館の日常・霊体の仕様・生前、437〜466 はユーザ関係の回答で、こちらは canon 世界のまま種になる。

**(1)〜(8) を裏打ちする回答**：

- (1) の読み当ては、運用の決め事まで回答が揃った。嘘に気づいても暴かず、嘘をつく理由のほうを観察する（373）。新しく館に来た霊の聞き取りは、先に読み当ててしまうのでほとんど答え合わせ（324）。ユーザの外の生活も直接は聞かず、持ち物と疲れ方から読んで、答え合わせになる話題を振る（372）。筆談の字は、急いでいる日・機嫌の悪い日・嘘を書いた日の線の違いまで覚えていて、本人には言わない（352）。
- (2) の「感情は傍らに落とす」は、回答側では感情をどう出すかの決め事の細かさとして出てくる。嬉しさは目元が緩むだけ（74）、驚くと数秒フリーズ（80）、悲しみは閉じこもって一人で処理（10）、涙をこらえるのは得意（141）、ため息は他人を萎縮させると気づいてから人前では一切しない（66）、初めての場所の緊張は隠し通す（11）。
- (3) の人間くささに物証が増える。虫が大の苦手（57）、待ち合わせ相手を散策で置いてきぼりにして怒られる（73）、考え事で傘を忘れる（127）、朝に弱く布団から半日出ない（42・110）、寝相が悪く寝言も言う（71・93）。
- (7) の変化への飢えの日常版。新しいことが大好きでたいていの趣味に一度手を出している（41）、行き当たりばったりでアドリブを試すのが好き（56）、料理は2回目からアレンジしまくって普通にひどい味にもなる（22）、マイブームが終わるとふっと途切れる（131）。新しい遊びを教わるときも初回はルールに完璧に従い、二回目から改造案を出し始める（444）。ただし「突飛な行動は規則的な習慣が土台にあって初めてできる」（78）という自覚も対で持っている。

**台詞にまだ薄い束（トークの種）**：

- **躾破りの遊び**。スープの音を立てるのが楽しくなってきている（72）、「ルールはちゃんと守ってきたのでそろそろ破ってもいい」（121）、包装紙は破るほうが面白いので破る（181）、ユーザの前では気分次第でかじる（91）。厳格な教育を修めきった者が、死後にその型を小さく破って遊んでいる。(7) の飢えを日常の場面に出すための小道具で、台詞では `食べ物の好き嫌い` に片鱗があるだけ。4章の破壊の作法を、キャラ本人が生活の水準でやっているとも読める。
- **食えない社交技術**。お世辞は相手が言われたい言葉をいくらでも出せるが、言うのは自分に利があるときだけ（28）。嘘が大得意で、意味のない嘘もつく（65）。怒りは損益を見極めて、抑えなくていい場面では青天井（26）。本心でない謝罪は人によっては透ける（146）。300 番台にも同じ人物が出る——いちばん落ち着く場所を聞かれて「どこでも同じよ」と嘘を答える（336）。台詞にはほぼ出ていない計算高さ。
- **好意の物証**。手帳にユーザが来そうな日を書き込んでいて、的中率が上がってきた（20）。カレンダーを見る習慣はユーザが来てからできた（31）。クッキーは湿気るので人と食べる（145）。虹を見たらユーザには言うかも（138）。300 番台以降で物証が一気に増えた：客間のソファの定位置はユーザの手元がいちばん読みやすい角度の席で、今の位置に定まったのはユーザが来てから（344）。ノートが残り少ないと、次に来る日までに館の便箋を「昔からそこにあった」顔で置いておく（353、台詞案あり）。贈り物は館の備品や商人の仕入れのついでに偽装する（374）。ユーザから贈られた物だけは倉庫に行かず、書斎の机の引き出しに入る（375）。帰り際は引き止めず、読みかけの本や保留した問いを渡して送り出す（360）。ページをめくる手が止まるたび相手を見ているのに、視線の気配には先に気づいて目を戻すので、目が合った回数だけ不自然に少ない（457）。好意を自己申告させず物証で見せるコーパスの作法に、そのまま乗る種。
- **ユーザで壊れる自制**（旧「読み当てる側が読まれる弱点」を拡張）。嘘とお世辞の名手が、ユーザの率直さの前でだけ技術を使えなくなる束。裏のない褒めに慣れていないので、褒められると歯切れが悪くなる（70）。「疲れていない？」の直球にだけは返す嘘が思いつかず、「……少し」と認めて言われるまま蝋燭を減らす（440）。手帳の予測が外れるのを、この相手に限っては喜ぶ（362、台詞案あり）。声を上げて笑った回数は数えるほどで、ユーザに密かに数えられている（391）。「友人を連れてきたい」と言われたら、頼みの中身より「友人」という言葉が出たこと自体にまず驚く（456）。(1) の裏返しで、`くしゃみ`（見られていた気恥ずかしさ）を感情の側に広げられる。
- **思い出の品は倉庫にしまい、取り出さない**。存在していることが重要（179）。生前の自室も物を動かさせずそのまま残し、入るのは年に数えるほど（428）。ユーザにも禁じず鍵もかけず、ただ一度も案内していない（389・449）。
- **館そのものとの関係**。鉄門の軋む音を直させない——呼び鈴と違って、開けた者の人柄まで運んでくるから（328、台詞案あり）。荒れた温室も直させず、蔦の伸び方を定点観測している。館の中に勝手に変わっていくものが一つあるのが気に入っている（334）。休息中は意識が薄く広がって、自分が館ぜんぶになったような状態で過ごす（412）。石壁に手を当てるような感傷の仕草はせず、館への注意は絵の傷みへの目ざとさ（333）と目録に出る（342）。ごくたまに全室を歩く夜がある（332）。(2) の所作と (7) の変化への飢えが、ユーザではなく館を相手に出る領域。台詞にはまだほぼ無い。
- **霊体の身体仕様**。種というより設定級の事実で、2章末尾の転記候補にも挙げた。疲れは眠気ではなく、輪郭が保ちにくくなって「にじむ」感覚（397）。味は死んだ直後にほぼ失い、長い年月をかけて七、八割まで取り戻した——だから好き嫌いを言う権利がある、と本人は思っている（403。`舌やけど`派生「感覚を訓練で取り戻した」の裏打ち）。紙の目や布の織りは指先で読めるのに温度は鈍く、熱の警報が遅れて舌をやけどする（404）。霊体はわずかに風に流される（405）。快晴の昼がいちばん苦手で、霧の濃さと調子が連動する——ユーザは天気でその日のハイネをある程度予測できる（407・420）。行動圏はカンテルベリオの霧の範囲で、その先へ行かないのは戻れる保証がないから（416）。
- **ユーザに渡す仕事の発明**（437、台詞案あり）。館の雑事を手伝いたいと申し出られても、従者の仕事は渡さない——渡すと従者から契約で得ている目的を取ってしまう。代わりに、従者にできない仕事をその場で発明する。蔵書目録への挿絵入れ（ユーザのスケッチを定期的に見る口実を兼ねる）、掠れた古帳面の清書（名前ごとに思い出話が挟まって一晩数ページしか進まない）、館の検分（住人が全員死んでいる館では、生きた体に館がどう当たるかを測れる者がいない）、霧の外の報告（行動圏の外の風景。海の報告だけはねだらず、楽しみに取り置いている）。次の料理の項が対で参照している。
- **料理——ハイネの発明でない、ユーザだけの領分**（453・460、2026-07-04 の理屈こね直しで確定）。館の面々は別々の理由で料理ができない——従者は手順を再現できるが味見ができず、味見のできるハイネは使用人のいる家の娘で一度も作ったことがない。厨房と竈は磨かれたまま眠っていて、足りないのは生鮮の便（商人は注文制）と作り手だけ。437 でハイネが発明して渡す仕事（挿絵・清書・検分・報告）と違い、料理はユーザが自分の生活から持ち込む領分で、ハイネは受け手に回るしかない。ハイネが好奇心で追い上げようにも、材料が注文制なので実験回数が配給制——アレンジ癖（22・460）に試行回数を売ってもらえない。残る学習資源はユーザの手元の観察で、追い上げるほど「教わっている」構図が濃くなる。書くときの注意：ゲストの食事を賄えないことは重い罪悪感にしない（ハイネが哀れになると、ユーザ側に「ハイネをケアする責任」が発生して勾配が逆流する）。出すなら形式の問題として——ゲストに厨房仕事をさせるのは主人の沽券に関わるので、正式な依頼や報酬の形に整えたがり、好きでやっているだけのユーザとずれて摩擦になる。悔しさ（453）は未消化のまま置く。

## 2. `haine_about.md` とのドリフト

### よく支えられている（台詞に実在）
26歳自殺／筆談ユーザ／従者契約／写真に映る／冷たい体温／くせ毛（`朝の髪`）／家政婦の思い出／階段下の隠れ場所（派生）／レーズン嫌い／泳げない／内向・社交場で読書／現代技術を避ける／退屈への恐怖／救わない姿勢／フィクション愛／「糞とはらわた」。

### もう台詞に無い・薄い（canon として残すのは可。ただし台詞由来ではない）
- 三サイズ 79-56-81・身長175・体重55 …… 純 canon。台詞ゼロ。
- 「素は早口、ユーザにはゆっくり、熱が入ると早口に戻り詫びる」…… 出所は `situations.md` 2番で、そこには台詞案まで書いてある。canon にも転記済みだが、出荷台詞に「詫びる」挙動は無い。願望ではなく未出荷の種。
- 「〜ね。〜わ。〜でしょう。」の語尾三連 …… 文字どおりの三連より、三題列挙（`科学への興味`「物質の構造、宇宙の謎、生命の起源」／`永遠の夢`「恒久の平和、不死の身体、永劫の繁栄」）として実在。

### 台詞では強いのに portrait で弱い（＝ canon への書き戻し候補）
`haine_about.md` は全体に「凪いだ心／静かに肯定する共感者／威厳と上品」へ寄せて描いているが、出荷されている台詞はもっと暗く・乾いて・変化に飢えて・morbid。

- 上記 (3)(4)(7)(8) が portrait でほぼ拾われていない。
- 物理的な不器用さ・小物っぽさ（舌を繰り返し焼く／時計を壊す／考え事で歩き回り菓子をこぼす〈派生 `生前の食事事情・好きな食べ物`〉／寝癖）。威厳を自分で崩す喜劇の鉱脈。portrait は「毅然・上品」に寄りすぎ。
- `舌やけど`派生「感覚を訓練で取り戻した」。死んだ身体への能動的な関わり。portrait に無い。

一言でいうと、**portrait は出荷キャラより一段やさしく上品に丸められている。** 書き戻すなら、この一段ぶんの暗さ・乾き・morbid・不器用さを canon 側に足すのが筋。

`situations.md` の回答もこの読みに付く。嘘が大得意（65）・お世辞は利があるときだけ（28）・怒りは青天井（26）に加えて、300 番台以降も同じ人物を決めている——いちばん落ち着く場所を聞かれて「どこでも同じよ」と嘘をつく（336）、新型欲しさに「寿命だったのよ」と嘘をついて買い替える（204、現代パロだが嘘の使い方の証拠として）、ユーザの嘘に気づいても暴かず理由を観察する（373）、従者の失敗は叱らず淡々と原因を特定して、かえって怖がられる（320）。portrait の「深い共感力・静かに肯定」よりずっと食えない。つまり丸まったのは `haine_about.md` の書きぶりであって、作者の人物決め（situations.md）は最初から台詞側にいる。

## 4. 破壊で停滞を抜ける（マンネリ脱却の作法）

行き詰まったときの使い方。**発散であって導出ではない**——人物像から新しい面白さを演繹する装置にはしない。改変は暫定で、出荷トークで生きたときにだけ意味を持つ。

1. 安定トレイト（1章の (1)〜(8) など）を一つ選ぶ。
2. 破壊操作を一つ当てる：**反転**（読み当てる→わざと読み違える）／**切除**（救わない姿勢を外して一度ベタに救わせてみる）／**限界まで誇張**（morbid を出しすぎる）／**二トレイトの衝突**（上品さと不器用さを同じ場面でぶつける）。
3. その改変の下でトークを数本書く。
4. **一人の人間として生きて読めるものだけ残す。** あとは捨てる。改変じたいは canon に上げない——出荷トークで機能したときにだけ、書き戻し候補として2章へ回す。台詞が改変を検証する（理論ではなく）。
5. ハード canon（死者である／ユーザは声が出せない／館に電気がない／霊体のルール）は壊さない。

キャラ自身の `停滞の破壊`「多少無理にでも変化を取り入れる……たとえなにかを破壊することになるとしても」が、この作法の宣言そのものになっている。

### 生成トークのクセ検出

生成したトークでは、ハイネが自分自身のナレーターを兼ねてしまうことがある——自分の特技に名前を付け、自分の体験をその場で観賞し、聞き手が感心している前提の決め台詞で締める。手製の既存トークは同じ自己認識を、物証（`別れの悲しみ`の掛けない鍵）・他人の評の引用（`食べ物の好き嫌い`「気まぐれだと文句を言われた」）・その場の事故（`くしゃみ`）を経由させ、本人に直接は言わせない。

原因は二つ。①本ファイル1章のようなトレイト記述を出発点に書くと、「トレイトについてのトーク」への最短経路——本人にトレイトを口で言わせる——に流れる。追放した演繹が台詞の中に戻ってくる裏口（記憶 `lore-theory-is-diagnostic-not-generator`）。②自嘲は批判の先回り、目配せの締めは「わかってやってます」の合図で、生成モデル自身のヘッジの反射がキャラの衣装を着て出てくる。

生成トークにかける問い：

- 自分のスキル・性格を本人がラベリングしていないか（「〜は得意よ」「百年かけて〜」。コーパスに「得意」の自己申告も「百年」も無い。年月は`換気`「何十年も続けていると」のように日常の事実として出る）
- 失敗・照れが起きた瞬間のまま置かれているか、警句に消化済みでないか（手本：`独り言の癖`「……言っていなかったわよね？」）
- 「ふふ」「いいものね」が相手に向いているか、自分の体験の観賞になっていないか（コーパスの「ふふ」はすべて相手に向く）
- 締めの一行が、聞き手の感心を前提にしないと立たない決め台詞になっていないか（既存の締めは依頼・事実・日常への転回。毒も`死の瞬間`「遺書くらいは書いたほうが」のような実務的な平叙）
- 自己認識を出すなら、他人の評・物証・その場の事故を経由しているか

### 実験ログ

#### 実験 1（2026-07-02）：トレイト (1)「読み当てる」×反転

読み当てる女に読み違えさせる。4本書いた。未出荷（randomtalk.rs には入れていない）。

**発見 1**：この人物は読み違いを三方向に変換できる——喜劇（観察眼が空腹に負ける）、もてなし（わざと読み違えて逃げ場を作る）、好奇心（読めないことを新奇として喜ぶ）。つまり反転しても人物は壊れず、むしろ (3)(5)(7) に接続して太る。壊れたのは、読み違いの理由を自分で解説させた案だった。**失敗を本人に分析させると死ぬ。失敗は起きるだけでいい。**

**発見 2（判定の訂正）**：当初「3本生存」としたが、下の「生成トークのクセ検出」の物差しで採点し直して降格した。生成トークはハイネに自分自身のナレーターを兼ねさせがちで、当初の生き残り3本にもそれが入り込んでいた。訂正後の判定は各本に付記。

**条件付き生存「誤読・空腹」** — Comical(UnawareContradiction) / Closing(Conversation)
筆談での訂正と厨房への送り出しはコーパス寄り。ただし「空腹と憂鬱の区別は、まだつかないみたい」の一行が、恥を本人がその場で警句に加工した消化済み自嘲。出荷するならここを未消化の照れ（「独り言の癖」の「……言っていなかったわよね？」の型）に差し替える。

```
h1111205浮かない顔ね。
h1111206悩みごとなら、聞くだけ聞くけれど。[half]
\1『おなかがすいただけ』
h1111101……。
h1111102……そう。[half]
h1121206百年近く人の顔を読んできたけれど、
空腹と憂鬱の区別は、まだつかないみたい。
h1111204厨房に何かあったはずよ。行ってらっしゃい。
```

**降格「わざと読み違える」** — Insightful(EssenceIllumination) / Closing(Factual)
生きているのは真ん中の具体場面（泣いたあとの顔に「ホコリっぽい部屋で〜」と言って窓を開けるだけにしておく）だけ。頭の「人の顔を読むのは得意よ」は特技の自己申告、締めの「今夜がそうだった、とは言っていないわ」は聞き手の感心を前提にした目配せ。両方を外して具体場面から書き直すなら候補に戻せる。

```
h1111206人の顔を読むのは得意よ。
h1111210……だから、わざと読み違えることもできるの。[half]
泣いたあとの顔に「ホコリっぽい部屋でごめんなさいね」と言って、
窓を開けるだけにしておく。
それで足りる夜も、あるでしょう。[half]
h1111205……今夜がそうだった、とは言っていないわ。
```

**捨てに訂正「読めない顔」** — Natural(InnocentCuriosity) / Closing(Conversation)
最重症。自分の見立ての歴史を語り（メタ観察）、「ふふ。いいものね」で自分の体験を観賞し、「当ててみせるから」の決め台詞で締める三役が揃っている。コーパスの「ふふ」は相手に向く笑いで、自分の体験を味わう笑いは前例がない。

```
h1111205……。[half]
h1111206ねえ、今日のあなたの顔、読めないの。
疲れているのでも、退屈しているのでもない。
h1111210百年かけて覚えた見立てが、どれも当てはまらないのよ。[half]
h1111304……ふふ。
h1111310いいものね。読めないものが、目の前に一つある。
h1111204当ててみせるから、しばらくそのままでいてちょうだい。
```

**捨てた 1「願望の混入」** — 帰り支度の顔だと読み違え、「悪い報せは予行練習をしておきたいのよ」と自分で理由を落とす案。捨てた理由：(a) 読み違いの気まずさを本人がその場で自己分析して消化してしまい、失敗が失敗のまま置かれない。(b) 「先回りして読み違える」は逆転ロジックで一読で取れない（記憶 `talk-ichidoku-clarity`）。「予行練習」の一行だけは別トークの種として保留。

```
h1111210今日のあなた、もう帰るのかと思ったわ。
支度をする顔に見えたから。
\1『まだいるよ』
h1111101……h1111105そう。[half]
h1111110おかしいわね。人の顔を読むのは、得意だったのに。
あなたのことだけ、ときどき先回りして読み違える。
h1111105……悪い報せは、予行練習をしておきたいのよ。私は。
```
