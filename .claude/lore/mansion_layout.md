# ハイネの館 — 設備・部屋の詳細

トーク作成時に館内の描写が矛盾しないよう、部屋・設備・家具の設定を一元管理する。

## 確定済み（コード・設定に記述あり）

### 部屋

| 部屋 | 根拠 | 備考 |
|------|------|------|
| 客間（居間） | first_boot, talk.rs | ユーザとの主な対話場所。向かい合うソファ、テーブル、蝋燭 |
| 書斎 | talk.rs, menu.rs | 蔵書室兼用。没入度で移動。Abstractトーク専用 |
| 玄関ホール | first_boot | 重い扉、暗い、石畳へ続く |
| 客室（寝室） | menu.rs | 常備されている宿泊用の部屋 |
| 階段・踊り場 | first_boot | 上階へ続く。階段下はハイネの幼少期の隠れ場所だった |
| 厨房 | situations.md 453・460 | 磨かれたまま眠っている。竈は百年火が入っていないが、整備されていてすぐ使える。商人からの物資（保存食・茶葉）の保管場所として現役。生者の食事が出ないのは設備でなく体制の問題——生鮮の便がなく（商人は注文制）、味見のできる作り手がいない |

### 外部

| 要素 | 備考 |
|------|------|

### 明示的にない設備

- 電気・電灯
- 現代的電化製品すべて
- 生者に食事を出す体制（厨房と竈は現存し整備済み。ないのは生鮮食品の定期便と、味見のできる作り手——situations.md 453・460）

## 未確定（あって自然だが未言及）

### 部屋

| 部屋 | 理由 |
|------|------|
| 食堂（ダイニング） | 大きな別荘なら客間とは別にあるのが自然。長テーブル、燭台。現在は使われず埃をかぶっている可能性 |
| 浴室・洗面所 | 19世紀の大邸宅なら簡素な浴室はある。鋳鉄の浴槽、水差し。ユーザが滞在するなら必要 |
| 化粧室（トイレ） | 同上。ユーザの生活に必須 |
| 廊下・回廊 | 大規模な館なら長い廊下がある。石壁、ランプ掛け |
| 地下室/貯蔵庫 | ワインセラー、薪・石炭の保管。ヨーロッパの古い邸宅には一般的 |
| 屋根裏 | 物置、古い家具・衣類・文書の保管 |
| 使用人の部屋 | かつて必要だったほどの規模→使用人用の小部屋群があったはず。現在は空室 |
| 礼拝室/祈祷室 | 19世紀の上流階級の別荘にはありうる。小さな祭壇、ステンドグラス |
| 温室（コンサバトリー） | 英国風邸宅ならありうる。現在は荒廃して蔦が伸び放題か |

## 客間（居間）の小道具詳細

ユーザとハイネが普段いる部屋。トークのデフォルト場面。

### 確定済み（トーク・コードに言及あり）

| 小道具 | 言及箇所 | 描写の例 |
|--------|----------|----------|
| 向かい合うソファ | first_boot | 「部屋の中央、向かい合ったソファの手前側に座る人影」 |
| テーブル | first_boot, randomtalk, bootend | お茶・蝋燭・菓子が置かれる中心的な家具 |
| 椅子 | first_boot | 「客間の椅子を指さすハイネの手」（ソファとは別に存在） |
| 蝋燭（複数本） | randomtalk多数 | テーブル上、燃え尽きた交換描写あり |
| ティーカップ・ティーポット | first_boot, menu, randomtalk | 「カップとポット。ティーセットだ。浮いている」 |
| 窓 | randomtalk | ハイネが外を見る、かすかに開けて換気 |
| 重いカーテン | first_boot, bootend | 「長いあいだ開いていないようだった」 |
| 本 | randomtalk | ハイネが読書、菓子を切りながら片手で開く |
| 毛布 | randomtalk | 奥から持ってきて差し出す |
| 菓子 | randomtalk, bootend | 切り分ける描写、ハロウィン時の特別な菓子 |

### あっておかしくないもの（未言及だが自然）

#### 家具・大型

| 小道具 | 理由 |
|--------|------|
| 暖炉 | 薪・石炭暖房と明記。蝋燭だけでは暖が取れない。客間にあるのが最も自然 |
| マントルピース | 暖炉があれば付随する。時計や蝋燭立てを置く場所 |
| サイドテーブル | ソファの横にあるのが自然。マッチ箱、蝋燭の予備、読みかけの本など |
| 本棚（小型） | talk-guideのステップ0で「居間の設備: 本棚」と明記済み。書斎ほど大きくはない |
| 絨毯・ラグ | 石の床の冷たさを和らげる。色褪せた模様。足音を吸収する描写に使える |

#### 照明・火器

| 小道具 | 理由 |
|--------|------|
| マッチ箱 | 蝋燭を点ける描写があるなら必須。テーブルかサイドテーブルに置いてある |
| 燭台（卓上） | 蝋燭を立てるものがなければ蝋が垂れる。金属製か陶器製 |
| 火かき棒・火ばさみ | 暖炉があれば付随する道具セット |
| 薪籠 | 暖炉脇に薪を入れておく籠 |

#### 飲食関連

| 小道具 | 理由 |
|--------|------|
| トレイ（盆） | 従者がティーセットを運ぶ際に使う。浮いたトレイという描写も可能 |
| 砂糖壺 | 紅茶の文化圏なら自然。銀製か陶器製の小さな壺 |
| ミルクピッチャー | 同上。ただし牛乳の調達が霊体商人頼みなので、ない可能性もある |
| ティースプーン | カップがあるなら |
| 菓子皿・菓子切り | 菓子を切り分ける描写があるので、ナイフと皿がある |
| ナプキン（布） | 上品な茶の時間には自然 |

#### 文具・筆記

| 小道具 | 理由 |
|--------|------|
| 紙・便箋 | ユーザが筆談に使う。テーブルの上に常備されていそう |
| 万年筆・ペン | randomtalkで「万年筆の走る音」の言及あり |
| インク壺 | 万年筆に付随。ハイネの時代ならつけペンも |

#### 装飾・その他

| 小道具 | 理由 |
|--------|------|
| クッション | ソファにあるのが自然。刺繍入りの古い物 |
| 絵画 | 壁に掛かっている。風景画や静物画 |
| 花瓶 | 中身は造花か乾燥花。生花の調達は難しい |
| 鏡（壁掛け） | 大きな邸宅の客間にあるのは自然 |
| 振り子時計 | talk-guideのステップ0で「居間の設備: 振り子時計」と明記。ガラスケース付き |
| 飾り棚 | 小物や陶器の人形などを並べる |

### ないもの・あったら不自然なもの

| ないもの | 理由 |
|----------|------|
| 電気スタンド | 電気なし |
| ラジオ・蓄音機 | 現代的電化製品は一切なし。蓄音機は時代的にはありうるがハイネが現代技術を避けている |
| 新聞・雑誌 | 定期購読の手段がない。ハイネの情報過多回避の方針に反する |
| 煙草・灰皿 | ハイネが喫煙者である描写なし |
| 酒瓶・グラス | 客間で飲酒の描写なし。地下にワインセラーはありうる |
| 生花 | 調達困難。管理不十分な庭なので花が咲いているか不明 |
| 写真立て | 霊体は写真に写らない。生前の写真があるかもしれないが飾るかは別問題 |
| 電話機 | 通信手段なし |
| ぬいぐるみ・人形 | 雰囲気に合わない。古い陶器のビスクドールなどは邸宅にあってもおかしくはないが客間向きではない |
| カレンダー | 時間感覚が希薄な霊体にとって不要 |
| 鍵付きの箱・金庫 | 客間にはない。書斎や寝室にある可能性 |
| 楽器（ピアノ等） | 客間にはない。別の部屋（音楽室）にある可能性はある |
| ペット用品 | 動物の描写なし |
