# 実装詳細: マウスインタラクション（単層モデル R1）

単層モデル R1 が現行方針（commit `47436e4` で確定）。従来の **3段階制（警戒→動揺→受容）はコードから完全撤去済み**——`RELATIONSHIP_STAGE`・`EventFlag::RelationshipGate`・`PendingEvent::RelationshipTransition` はいずれも存在しない。トーク作成方針は本ファイル末尾「トーク作成方針」節（旧 talk-guide から 2026-07-05 に退避）。

## 設計の核心（不変）
- ハイネの防壁はすべて**言語の上に乗っている** → 触覚（非言語）はその外側にある
- ユーザの武器は非言語（沈黙・身体的接触）、ハイネの武器は言語
- **観察眼は健在**：全反応で。ユーザにとっての命綱であり、削る対象ではない。変わるのは「観察で得たものをどう扱うか」のみ

## R1・単層プール

- マウス反応は**段階で深まらない**。部位別（head/face/hand/shoulder/mouth）の**単層プール**から提示する
- 各反応は**言と行の乖離**（言葉は平静を保とうとし、身体や声が欲をそっと裏切る）を一つの反応の中に内包し、**永続の価値**（鑑・掴み・失う地平）で色づく。段階分岐・ゲート・進行変数は持たない
- 関係の「解れ」は触覚進行ではなく **OnBoot/OnClose の機微＋永続の地平＋OnVanishSelecting の唯一の帰結**が担う
- **mouth**：常時利用可（旧「段階3で解禁」は撤廃済み）
- **削除済み**: bust, skirt（R1でも復活させない）
- トーク作成の指針（単層での表現方針、`\\1`視点の使い方等）は下記「トーク作成方針」節

## 存続する技術機構

- **チェイントーク**：ランダムトーク→制限時間内に部位を触る→特殊反応。「ハイネの言語にユーザが非言語で返答する」構図は新モデルの中核。`ChainTalkState`構造体（`variables.rs`）、`CHAIN_TALK_STATE` volatile変数、`check_chain_talk()`（`mouse.rs`）、`\\p[2]`ヒント表示、自動テスト `mouse::tests::test_chain_talk_mechanism`
- **蝋燭操作（没入度・居間⇔書斎）**：`two_candle_double_click`
- `talk(text)`：通常トーク（マウス反応のプール提示に一本化）

## トーク作成方針

旧 talk-guide スキル「マウスインタラクションのトーク作成方針」節（2026-07-02 廃止）から退避。R1 でのマウス反応トークを書くときの指針。

### 単層反応の表現方針
- 一本の反応の中に**言と行の乖離**を同居させる：ハイネは口で逸らす／分析する／皮肉る（言語の防衛）が、身体は裏切る（息を呑む・目を伏せる・手が動く）。「段階で深まる」のではなく、**一本の中に防衛と漏れが共存**する
- **観察眼は健在**：ユーザの手の動き・表情を正確に捉える。捉えたものを分析として返すか言語化せず感じるかは反応ごとに振れてよいが、観察力そのものは全反応で保つ
- ハイネが触覚でユーザを理解する眼で色づけてよい（癖を拾って意味づける形の好意は可）。ただし**価値を剥き出しで自己申告させない**。「あなたが必要」と言わせず、観察と身体反応で漏らす
- 関係の「解れ」を触り反応で進行させない。深まりは OnBoot/OnClose・永続の地平・OnVanishSelecting が担う

### `\\1`視点の活用
- `\\1`は**ユーザの独白**（受動的表現・三人称的描写は誤り）
- 客観描写（「冷たい髪が指の間を滑る」）も、ハイネの身体反応の目撃（「一瞬だけ、力が抜けた」）も、双方向の交流（「向こうから指が絡んだ」）も、**段階に縛られず**反応に応じて選ぶ

### 避けるべき表現
- 立場のひけらかし、感情の冗長な説明、過去の詳細開示
- 死への軽々しい言及、中途半端な受容（「嫌いではないけれど」等）
- **段階前提の台詞**（「前より震えなくなった」等、過去の段階を参照する文）。単層では文脈が断絶するため使わない

### チェイントークの作成要件
「ハイネの言語にユーザが非言語で返答する」構図を体現する（新モデルの中核）。トーク内容自体がヒントになること（手について語った後に手を取る等）。`\\p[2]`でヒント表示。旧ゲート結合（段階遷移条件）は撤去済みで、チェインは段階非依存の独立機構として存続。
